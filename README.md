# Vice Lights Cover Studio

An offline web app that turns photos + captions into GTA 6-style cover art, exported as PNG.

- 6 poster layouts (Hero + 3, Grid 4, Full bleed, Nine grid, Triple strip, Tilted snaps)
- 5 gradient-map grades (Sunset, Neon, Noir, Palm, Candy)
- 4 photo slots with drag-to-crop, zoom, and 4 sample photos
- Captions with Anton titles, Pacifico tagline, badge ribbon, and heat meter
- Film grain, vignette, and halftone finish; 4 export sizes; 20-step undo/redo

Entry for the [gta6-cover-art-01 bounty](https://make.fun/bounty/gta6-cover-art-01) on make.fun.
